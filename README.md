# Resume — thegalkin

Двуязычная страница-резюме (RU/EN) на GitHub Pages.

- `index.html` — основная страница
- `styles.css` — стили
- `i18n.js` — переводы
- `app.js` — переключатели языка и темы
- `assets/resume_ru.pdf` — PDF-версия резюме
- `CNAME` — кастомный домен `thegalkin.com`
- Яндекс Метрика 66785497

## Локальный запуск

```bash
python3 -m http.server -d . 8000
# http://localhost:8000
```

## Деплой

Push в `main` — GitHub Pages обновится автоматически.
